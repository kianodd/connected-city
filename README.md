# شبکه‌ساز: شهر متصل (Connected City)

بازی مدیریت شرکت مخابراتی فارسی و راست‌چین (RTL) به صورت وب — جاوااسکریپت خالص، بدون مرحله build.

## ساختار پروژه

```
connected-city/
├── index.html        # چیدمان: نوار بالا، پنل ساخت (راست)، نقشه (وسط)، پنل جزئیات
├── css/style.css     # تم تیره، RTL، واکنش‌گرا (<900px پنل‌ها جمع می‌شوند)
├── js/
│   ├── data.js       # (توسط ایجنت دیگر) GAME_DATA: مناطق، ساختمان‌ها، کاتالوگ تجهیزات، فناوری‌ها، بسته‌ها، مأموریت‌ها
│   ├── sim.js        # (توسط ایجنت دیگر) GameSim: newGame, buildNode, connect, tracePath, computeFlow, tick, saveGame, loadGame, unlockTech, isUnlocked
│   ├── map.js        # (توسط ایجنت دیگر) CityMap: init(canvas,state,{onSelect,onPlace}), لایه‌ها, highlightPath
│   ├── ui.js         # GameUI: رندر نوار بالا/منوی ساخت/جزئیات/پنجره‌ها/آموزش/توست
│   └── main.js       # راه‌اندازی، حلقه بازی (rAF + tick)، ذخیره خودکار، میانبرها
└── README.md
```

## اجرای محلی

ساده‌ترین راه: فایل `index.html` را در مرورگر باز کنید. برای جلوگیری از محدودیت‌های `file://` بهتر است سرور محلی اجرا کنید:

```bash
cd connected-city
python3 -m http.server 8000
# سپس: http://localhost:8000
```

## کنترل‌ها

- **انتخاب**: کلیک روی گره/ساختمان → جزئیات، مسیر تا دروازه و مشکلات نمایش داده می‌شود.
- **ساخت**: از منوی ساخت یک تجهیز انتخاب کنید، روی نقشه کلیک کنید و در پنجره تأیید (هزینه/زمان/اثر) «ساخت» را بزنید.
- **اتصال**: ابزار «اتصال» → کلیک روی گره اول و دوم → انتخاب رسانه (فیبر/مسی/بی‌سیم/...).
- **تخریب**: ابزار «تخریب» → کلیک روی گره.
- **سرعت**: ⏸ مکث / ▶ عادی / ⏩ سریع؛ `Space` = مکث/ادامه.
- **بزرگ‌نمایی**: دکمه‌های +/− روی نقشه یا کلیدهای `+` و `-`.
- **لایه‌ها**: چک‌باکس‌های پنل راست (مناطق، ساختمان‌ها، اتصالات، پوشش، برچسب‌ها).
- **ذخیره**: دکمه 💾 یا ذخیره خودکار هر ۳۰ ثانیه در `localStorage`؛ برون‌بری/درون‌بری به صورت فایل JSON؛ ↺ = بازی جدید.

## خلاصه قوانین شبیه‌سازی

- تجهیز بدون مسیر کامل **مشتری ← دسترسی ← تجمیع ← هسته ← دروازه** هیچ سرویسی نمی‌دهد و در پنل جزئیات هشدار «متصل نیست» می‌گیرد.
- ظرفیت هر لینک/گره محدود است؛ اشباع باعث افت کیفیت، نارضایتی و هشدار 🔔 می‌شود. از پنل جزئیات می‌توان علت مشکل و گزینه‌های رفع (ارتقا، لینک موازی، مسیر جایگزین) را دید.
- درآمد از بسته‌های اینترنت (قیمت/سرعت قابل ویرایش) و تعداد مشتریان متصل می‌آید؛ هزینه‌ها شامل ساخت، نگهداری، حقوق و مالیات است.
- فناوری‌های جدید (فیبر، 5G، ماهواره و...) در «تحقیق و توسعه» باز می‌شوند و تجهیزات قفل‌شده 🔒 را فعال می‌کنند.
- آموزش ۸ گامی در شروع بازی: بررسی نقشه، نصب دسترسی، اتصال انتقال، اتصال هسته و دروازه، فعال‌سازی سرویس، رفع مشکل ظرفیت، گسترش منطقه، مسیر جایگزین.

## ساده‌سازی‌های نسخه ۱

- مدل جریان (flow) به صورت تجمیعی/روزانه است، نه بسته‌به‌بسته؛ `tick` هر ~۳ ثانیه یک روز بازی است.
- نقشه دوبعدی کانوس با لایه‌های ساده؛ بدون ساختمان سه‌بعدی یا انیمیشن ترافیک جزئی.
- کارکنان و قراردادها در سطح پایه‌اند (استخدام/حقوق) و شیفت‌بندی ندارند.
- رویدادها و خرابی‌ها تصادفی ساده‌اند؛ آب‌وهوا و فاجعه طبیعی در v1 نیست.
- ذخیره فقط محلی (`localStorage` + فایل JSON) است؛ بدون حساب کاربری یا چندنفره.

## PWA و نسخه‌بندی

- بازی یک PWA نصب‌پذیر است: `manifest.webmanifest` + `sw.js` + آیکون‌های `icons/`.
  روی اندروید (کروم): منوی مرورگر ← «افزودن به صفحه اصلی» / «نصب برنامه».
- استراتژی کش سرویس‌ورکر: کد (HTML/JS/CSS) همیشه **network-first** است (کش فقط پشتیبان
  آفلاین)، آیکون‌ها cache-first؛ نام کش از نسخه ساخته می‌شود و کش‌های قدیمی پاک می‌شوند.
- **نسخهٔ برنامه** در `js/version.js` (`APP_VERSION`) تنها منبع حقیقت است و در منوی کناری
  نمایش داده می‌شود. `push.py` در هر انتشار شمارهٔ patch را **خودکار** یکی بالا می‌برد و مهر
  `// build:` در `sw.js` را تازه می‌کند — نیازی به ویرایش دستی نیست.
- آپدیت داخل بازی: منوی کناری ← «بررسی آپدیت». اگر نسخهٔ جدید آماده باشد، بنر «نسخهٔ جدید
  آماده است» با دکمهٔ «اعمال آپدیت» می‌آید؛ ذخیرهٔ `localStorage` در آپدیت دست‌نخورده می‌ماند.
